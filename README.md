## Product Backlog: Batalha Naval Online

1. Modos de Jogo e Matchmaking

   US01: Como jogador, quero iniciar uma partida contra um robot, para que possa jogar sozinho sem depender de outro jogador disponível.
   
   US02: Como jogador, quero iniciar uma partida com um amigo através de um link único, para que possamos jogar em tempo real sem necessitar de conta.
   
   US03: Como jogador, quero iniciar uma partida contra um jogador aleatório online, para que possa competir com desconhecidos a qualquer momento.

2. Mecânicas de Jogo (Core Gameplay)

   US04: Como jogador, quero selecionar uma coordenada no tabuleiro adversário para disparar um míssil e tentar atingir um navio inimigo.

   US05: Como jogador, quero que o sistema identifique visualmente quando um navio foi totalmente afundado para que eu saiba quantos alvos restam.

   US06: Como jogador, quero que o jogo alterne automaticamente os turnos entre mim e o meu oponente para manter o fluxo da partida.

   US07:  Como jogador, quero receber feedback visual imediato ("Água" ou "Atingido") após cada disparo para planear o meu próximo movimento.
   
   US08: Como jogador, quero receber presentes (gifts) ao longo da partida ao atingir casas especiais no meu tabuleiro, para que possa obter armas especiais.
   
   US09: Como jogador, quero usar armas especiais (míssil simples, míssil grande, chuva de mísseis, míssil nuclear) contra o adversário, para que possa causar              danos em área e obter vantagem estratégica.
   
   US10: Como jogador, quero ser notificado quando ganho ou perco uma partida, para que saiba o resultado final claramente.

3. Interface e Experiência do Utilizador (UX/UI)

   US11: Como jogador, quero ver um cronómetro de turno para garantir que a partida avance e evitar que o oponente demore demasiado tempo.

   US12: Como jogador, quero enviar emojis ao meu adversário durante uma partida, para que possa comunicar emoções em tempo real sem texto.

4. Progressão e Social (Metagame)

   US13: Como utilizador registado, quero que as minhas vitórias sejam contabilizadas num ranking (Leaderboard) para comparar o meu nível com outros jogadores.

   US14: Como utilizador, quero poder escolher um nome de utilizador e um avatar personalizado para ser identificado facilmente na plataforma.

5. Torneios (Grupo)
   
   US15 — Como organizador, quero criar um torneio privado dando-lhe um nome e escolhendo o jogo, para que possa organizar competições com o meu grupo.
   
   US16 — Como organizador, quero escolher o modo de torneio (Leaderboard, Eliminação Simples, Eliminação Dupla, Suíço, Round Robin), para que possa adaptar o               formato ao tamanho e objetivo do grupo.
